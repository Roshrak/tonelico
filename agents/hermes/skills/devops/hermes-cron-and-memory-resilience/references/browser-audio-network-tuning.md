# Declarative Browser, Audio & Network Tuning on Tonelico NixOS

## 1. Sole Browser Architecture (`browsers.nix`, `environment.nix`, `base.nix`)
1. LibreWolf is the sole declarative browser across NixOS, Home Manager, XDG MIME defaults (`~/.config/mimeapps.list` -> `librewolf.desktop`), KDE shortcuts (`[services][librewolf.desktop]` in `~/.config/kglobalshortcutsrc`), and `Super+Z`/`Mod+Z` in all Wayland compositors. Chromium (`chromium-nixpkgs`, `chromium-latest`, `/etc/chromium/policies/managed/default-browser.json`, `~/.local/bin/chromium*`) and all Chrome PWAs (`chrome-*-Default.desktop`) are removed.
2. When launching GUI helpers under `systemd-run --user`, auto-detect `wayland-1` vs `wayland-0` (`if [ -S "$XDG_RUNTIME_DIR/wayland-1" ]; then WAYLAND_DISPLAY=wayland-1; else WAYLAND_DISPLAY=wayland-0; fi`) because Umbriel binds `wayland-0` while Niri and Hyprland bind `wayland-1`.
3. In `nixos/home/files/bin/clean-stray-sessions`, match both `librewolf` and `.librewolf-wrap` in `/proc/<pid>/comm` (`pgrep -u "$uid" -x 'librewolf|\.librewolf-wrap'`) when reaping stray browser processes from ended logind sessions.

## 2. LibreWolf Declarative Hardening, Adblock & Multi-Account Gmail Setup (`browsers.nix`)
1. Configure `programs.librewolf` in `nixos/modules/home/packages/browsers.nix`:
   - Lock `SanitizeOnShutdown = false` and `privacy.clearOnShutdown.* = false` so Google/Gmail sessions persist across restarts, while locking `"browser.startup.page" = 1`, `"browser.sessionstore.resume_from_crash" = false`, and `"browser.sessionstore.max_resumed_crashes" = 0` so closing LibreWolf closes all tabs without restoring stale sessions.
   - Set `SearchEngines.Default = "Google"` with a `Google` entry (`https://www.google.com/search?q={searchTerms}`, suggest URL `https://www.google.com/complete/search?client=firefox&q={searchTerms}`) and enable `browser.search.suggest.enabled` + `browser.urlbar.suggest.searches`.
   - Lock `HttpsOnlyMode = "force_enabled"`, `PostQuantumKeyAgreementEnabled = true`, `DNSOverHTTPS` (`ProviderURL = "https://security.cloudflare-dns.com/dns-query"`, `Fallback = true`, `"network.trr.mode" = 2`), `EnableTrackingProtection` (`Category = "strict"`), Total Cookie Protection (`"network.cookie.cookieBehavior" = 5`), active bounce-tracking protection (`"privacy.bounceTrackingProtection.mode" = 1`), Fission site isolation (`"fission.autostart" = true`), level-4 Linux content sandboxing (`"security.sandbox.content.level" = 4`), CRLite (`"security.pki.crlite_mode" = 2`), post-quantum TLS (`"security.tls.enable_mlkem1024" = true`, `"security.tls.enable_mldsa" = true`), and WebRTC IP leak protection (`"media.peerconnection.ice.no_host" = true`, `"media.peerconnection.ice.default_address_only" = true`).
   - Under `ExtensionSettings`, force-install `uBlock0@raymondhill.net` (`private_browsing = true`) and `@testpilot-containers` (`private_browsing = true`), and block `{7be2ba16-0f1e-4d93-9ebc-5164397477a9}` (Video Speed Controller).
   - Under `policies."3rdparty".Extensions."uBlock0@raymondhill.net"`, configure `adminSettings.userSettings` (`cnameUncloakEnabled = true`, `webrtcIPAddressHidden = true`, `prefetchingDisabled = true`, `hyperlinkAuditingDisabled = true`, `parseAllABPHideFilters = true`) and `toOverwrite.filterLists` (31 lists covering uBlock, EasyList, AdGuard Ads/Mobile/Spyware, EasyPrivacy, URLHaus Malware, Curben Phishing, Peter Lowe, Dan Pollock, Cookie Notices, Popup/Overlay/Widget/AI Annoyances, and `VIE-1`).
   - Enable `privacy.fingerprintingProtection = true` (`privacy.resistFingerprinting = false`, `privacy.fingerprintingProtection.overrides = "+AllTargets,-CSSPrefersColorScheme,-JSDateTimeUTC,-FrameRate"`) so dark mode, local `+07:00` timezone, high-refresh-rate Wayland, and WebGL (`webgl.disabled = false`) work without breaking Google apps.

### LibreWolf Pitfalls
- **AutoConfig `0x8000ffff (NS_ERROR_UNEXPECTED)`**: Put LibreWolf preferences exclusively under `programs.librewolf.policies.Preferences` and leave `programs.librewolf.settings` empty. Calling `defaultPref(...)` in `librewolf.overrides.cfg` on a preference already locked by `policies.json` (`Status = "locked"`) throws `0x8000ffff (NS_ERROR_UNEXPECTED) [nsIPrefBranch.setIntPref]` and blocks startup with a `Netscape.cfg/AutoConfig failed` modal dialog. When removing `programs.librewolf.settings`, also delete `<profile>/failover.jsc`, `<profile>/user.js`, and `~/.config/librewolf/**/librewolf.overrides.cfg` because `nsAutoConfig` falls back to executing cached `failover.jsc` when `librewolf.overrides.cfg` is absent.
- **Firefox/LibreWolf 140+ `moz_cookies.expiry` Milliseconds**: In Firefox/LibreWolf 140+ (`cookies.sqlite`), `moz_cookies.expiry` is stored in **milliseconds** (`int(exp_seconds * 1000)`), whereas Chromium CDP (`Network.getAllCookies`) and Playwright `storage-state.json` store `expires` in **seconds** (`~1.79e9`). Multiply second-based `expires` (`< 100_000_000_000`) by `1000` before inserting into `moz_cookies`, or Firefox treats the timestamp as January 1970 and purges every imported cookie at startup.
- **Connecting >10 Google Accounts**: Google caps a single browser cookie jar at 10 signed-in accounts (`/u/0/` through `/u/9/`). Store the first 10 in the default session (`originAttributes = ""`) and map additional accounts to Firefox Multi-Account Containers (`originAttributes = "^userContextId=N"` in `moz_cookies` + `identities` in `<profile>/containers.json`).

## 3. PipeWire/WirePlumber Audio & Network Stack Tuning
1. **Audio (`nixos/modules/system/audio.nix` & `nixos/hosts/tonelico/default.nix`)**:
   - Disable Intel HDA codec power-save (`options snd_hda_intel power_save=0 power_save_controller=N` in `boot.extraModprobeConfig` and `systemd.tmpfiles.rules`) to eliminate 10-second idle wake pops/clicks.
   - Keep default speaker sink volume at or below `1.00` (`0 dBFS`) via `wpctl set-volume @DEFAULT_AUDIO_SINK@ 1.0` to avoid software digital overdrive clipping.
   - Configure PipeWire `default.clock.allowed-rates = [ 44100 48000 88200 96000 ]`, `default.clock.quantum = 512` (`10.6 ms`), and `resample.quality = 10`.
   - Configure WirePlumber BlueZ HD codecs (`ldac` HQ, `aptx_hd`, `aptx`, `aac`, `sbc_xq`, `bluez5.enable-hw-volume = true`) and set `bluez5.enable-midi = false` to suppress `org.bluez.GattManager1.RegisterApplication() failed` errors.
2. **Networking (`nixos/modules/system/networking.nix`, `nixos/hosts/tonelico/default.nix`, `nixos/modules/features/gaming.nix`)**:
   - Disable Wi-Fi DTIM sleep (`networking.networkmanager.wifi.powersave = false`, `802-11-wireless.powersave = 2` on active NetworkManager profiles, and `options iwlwifi power_save=0` + `options iwlmvm power_scheme=1` in `boot.extraModprobeConfig`).
   - **Pitfall**: `/sys/module/iwlmvm/parameters/power_scheme` has `0444` read-only permissions in sysfs at runtime; configure it only via `boot.extraModprobeConfig`, never in `systemd.tmpfiles.rules`.
   - Keep `16 MB` TCP/UDP socket buffers (`net.core.rmem_max = 16777216`, `net.core.wmem_max = 16777216`, `net.core.netdev_max_backlog = 16384`, `net.ipv4.tcp_mtu_probing = 1`, `net.ipv4.tcp_slow_start_after_idle = 0`, `net.ipv4.tcp_notsent_lowat = 131072`, `net.ipv4.tcp_ecn = 2`).
