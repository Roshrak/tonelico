# Study modes

## teach-deep

Explain the requested source range line by line. Include mechanism, clinical meaning, exam trap, source label, and one application question per topic. Run a scope preflight before the final response.

## quiz-adaptive

Select weak or unmeasured concepts. Use a new context for every retry. Grade both answer and reasoning; record the attempt before choosing the next question.

## solve-exam

For every item, provide the course answer, source rationale, why alternatives fail, ambiguity status, and a separate current-practice note when needed. Mark missing data or faulty questions rather than inventing certainty.

## zone-review

Rank concepts into Tier A through D from slide emphasis, prior-exam recurrence, prerequisite centrality, and learner weakness. State the evidence behind every tier.

## finish-session

Summarize what is secure and fragile. Create source-verified flashcards only after the learner explicitly signals completion.
