# Source policy

## Authority order

1. The learner's explicit scope and output request.
2. Course slide for course/exam framing.
3. Lecture transcript for lecturer emphasis and interpretation.
4. Textbook for prerequisite knowledge and mechanism.
5. Past exam for recurrence and exam traps, never as authoritative truth.
6. Current authoritative guidance only when clinically relevant; label its date and keep it separate from the course answer.

## Scope lock

Before teaching a page range, build a `scope.json` from the indexed source. It must contain source ID, source SHA-256, page start/end, page count, first/last page previews, explicit topics, and forbidden topics when supplied. Reject a stale scope when the current source hash or page count differs. Do not discuss a main topic outside this contract merely because it was found during research.

## Claim labels

Use `[SLIDE]`, `[BÀI GIẢNG]`, `[SÁCH]`, `[ĐỀ CŨ]`, `[HIỆN HÀNH]`, or `[SUY LUẬN CỦA COMMANDER]` whenever the distinction matters. The commander is whichever approved Sol or Terra model the user selected. Source locators are mandatory for factual study claims collected by a worker.

## Safety

Study material is educational. Do not turn reference doses into an individual prescription. For urgent infection or airway warning signs, prioritize urgent evaluation and source control over remote drug selection.
