Problem proven by real runs: _builder_instruction sends the entire original request plus every implementation step and every acceptance criterion in one Aider call. For audit tasks this produced ~42k input and truncated output. The approved explicit token-limit gate correctly stops partial output, but prevention is needed.

Change initial build orchestration to execute plan implementation_steps as bounded sequential Aider slices from the same clean worktree, instead of one monolithic Aider request, when the plan has more than one step. Each slice:
- receives only plan objective, that single implementation step, hard constraints, necessary acceptance criteria selected conservatively (if reliable mapping is unavailable, omit detailed criteria and state tests+Sol review are final gates), and the minimal allowed file subset. For this slice, use the plan's full allowed_files only when no deterministic narrower subset is encoded; do not invent file ownership.
- must not include the full original request, other implementation steps, previous conversation, or full acceptance list.
- gets a unique label builder_step_001, builder_step_002, etc. Existing Aider run token-limit detector applies independently.
- after each slice, run scope check and source-isolation check. Do not run final tests or Sol review until all slices complete. If any slice fails/token-limits, stop immediately and preserve candidate; do not continue remaining steps.
- bounded maximum number of steps (e.g. 12) validated before dispatch; empty steps rejected. Single-step plans retain one call with concise objective+step, not full original request.
- persist a builder_slices.json manifest before dispatch with ordered step index, label, allowed files and SHA256 of each generated instruction, but never raw prompts/credentials. On resume, token-limited/failed retained candidates are not automatically continued; successful in-progress resume behavior may remain deferred and fail closed.

Do not implement automatic Luna recovery, credential redesign, test-count redesign, global budgets or docs in this slice.
