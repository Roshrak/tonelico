  "blockers": [
    "Structured steps call require_keys(s_item, {\"step\"}, ...), then attempt to process the optional editable_files key. The validator must explicitly permit exactly step plus optional/required editable_files. In addition, _builder_slice_instruction receives the entire dictionary instead of s_item[\"step\"], causing the Builder instruction to contain a Python dictionary representation rather than the validated instruction text.",
    "extract_step_contract silently weakens unsatisfiable exact and minimum contracts by clamping them to eight. For example, \"exactly 9 steps\" returns (8, 8), allowing a plan that directly violates the request, and \"at least 9 steps\" also becomes (8, 8). A range wholly above eight can produce an inverted pair such as (9, 8). Contracts that cannot intersect the hard 1-8 system limit must raise a contract error; exact values must never be silently rewritten.",
    "The non_resumable flag is still inferred from list(run_dir.glob(\"*.token_limit.json\")) in the exception handler, so its authoritative state depends on a leftover filesystem artifact. Conversely, resume rejects every state whose error_category is \"builder\", even when non_resumable was never set and the builder failure was not output truncation. Truncation must be classified directly at the point it is detected and persisted as non_resumable independently of artifacts; resume should use that authoritative flag rather than conflating all builder errors with truncation.",
    "Discarding a non-resumable worktree with shutil.rmtree directly leaves the Git worktree registration and administrative metadata behind. Use the existing Git-aware worktree cleanup/removal path, with a filesystem fallback only after administrative cleanup."
